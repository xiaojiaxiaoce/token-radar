A token launch radar. It reads a sealed snapshot of the protocol universe and ranks 198 token launches by implied value — every watchlist protocol covered, each row with a five-step farm plan — then renders a static dashboard (board, detail and filtered views) and a judging dossier. Pure Node.js standard library: no dependencies, no network.

## Run it

```sh
node main.ts
# reads /input/snapshot.json; writes board.json, the dashboard and dossier.json to /output
```
